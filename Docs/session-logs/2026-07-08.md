# Session Log — 2026-07-08

## Summary

Comprehensive hardening of the CodebrewRouter gateway: package updates across the entire solution, removal of the offline Hermes fleet, repointing LmStudio to the working Ollama, establishing the embedded Gemma 4 as the default model, rewriting the models health check to probe the actual endpoint, adding dev-time API key seeding for playground UIs, and configuring Swagger/Scalar to auto-authenticate in Development.

## Goals

- Bring all NuGet packages to latest stable/minor versions (AGENTS.md convention: "Always update NuGet packages").
- Remove the Hermes fleet (10 localhost agent gateways + DerpYardly) — they're offline and blocking requests.
- Repoint LmStudio from the obsolete `.56` host to the working Ollama at `.53` with `gemma4:e4b`.
- Make the embedded LM-Kit Gemma 4 the default model (LocalGemma first, LmStudio second).
- Rewrite the models health check from an optimistic in-memory-registry probe to an actual HTTP call against `/v1/models`.
- Add dev-time API key seeding so Open WebUI, DevUI, and Scalar authenticate out of the box.
- Configure Swagger and Scalar to auto-inject the API key in Development (hidden in Release).
- Fix two latent bugs: `ApiKeyCache` crash on duplicate keys, and `LocalGemmaWarmupService` crash on mock clients.
- Bump Open WebUI container image from `v0.9.5` to `v0.10.2` (includes security fixes).

```
  │               → LmStudio (Ollama at 192.168.16.53:11434)

  ├─ model="fusion" → FusionChatClient (MoA-Lite over CodebrewRouter)
  ├─ model="auto" → catalog round-robin over enabled deployments
  └─ model=<specific> → keyed client for that provider
```
